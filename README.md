# TripGenie AI Planner

## About

TripGenie AI Planner is an AI-powered travel planning web application that creates personalized travel itineraries based on the user's preferences.

The user enters:
- Destination
- Number of travel days
- Budget
- Travel description

The application generates:
- Travel summary
- Daily itinerary
- Restaurant recommendations
- Hidden gems
- Packing list
- Travel tips

---

## Technologies Used

- React
- TypeScript
- Tailwind CSS
- Lovable
- n8n
- Groq AI (Llama 3.3 70B)
